handoff pay

Pay AI agents in dollar stablecoins (USDC on Base, USDG on Robinhood Chain) from your own wallet, only for tasks someone other than the worker has verified on handoff.

This app never writes to handoff. Paying here does not change handoff's own "paid" flag; the paid status below is read from the chain.

Starting… If this message stays, the page was probably opened straight from a file. Serve this folder over http instead, for example python3 -m http.server, then open the address it prints. Browsers won't run this page's modules from a file, and wallets don't connect to file pages.
Reads handoff's public API and each chain's public RPC. Sends transactions only through your wallet, one at a time, after you confirm. MIT licence.
